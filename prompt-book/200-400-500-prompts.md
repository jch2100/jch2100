# 도메인 1: 재무설계 (Financial Planning)

---

## 카테고리 1. 고객 재무 니즈 파악 질문 설계

---

**[FP-01] 초기 상담 니즈 탐색 질문지**
도메인: 재무설계
용도: 첫 상담 시 고객의 재무 목표와 현황을 체계적으로 파악
프롬프트:
```
---
나는 재무설계사입니다. 신규 고객과의 첫 상담을 앞두고 있습니다.
고객 정보: [나이], [직업], [가족구성], [상담 신청 계기]

아래 기준으로 초기 니즈 탐색 질문을 설계해주세요.
1. 라포 형성용 오프닝 질문 3개 (부담 없이 대화를 여는 질문)
2. 재무 현황 파악 질문 5개 (수입/지출/자산/부채)
3. 미래 목표 탐색 질문 5개 (단기/중기/장기 목표)
4. 리스크 인식 파악 질문 3개 (보장, 투자 손실 허용 범위)
5. 우선순위 확인 질문 2개 (가장 급하게 해결하고 싶은 것)

각 질문은 개방형으로 작성하고, 고객이 방어적으로 반응하지 않도록 중립적인 어조를 유지해주세요.
---
```
효과적인 이유: 상담 흐름에 맞게 단계적으로 설계되어 고객 저항 없이 깊은 니즈를 끌어낼 수 있음

---

**[FP-02] 고객 라이프스테이지별 맞춤 질문 세트**
도메인: 재무설계
용도: 생애주기에 따른 재무 이슈를 선제적으로 파악
프롬프트:
```
---
고객의 라이프스테이지: [신혼기 / 자녀양육기 / 자녀교육기 / 은퇴준비기 / 은퇴기 중 선택]

이 라이프스테이지에서 고객이 가장 자주 겪는 재무적 고민 TOP 5를 먼저 설명하고,
각 고민에 대응하는 상담 질문을 2개씩 작성해주세요.

질문 작성 조건:
- 고객 스스로 문제를 인식하도록 유도하는 질문
- 전문용어 없이 일상 언어로 작성
- 답변 후 자연스럽게 솔루션 제안으로 연결 가능한 구조
---
```
효과적인 이유: 고객이 미처 인식하지 못한 재무 공백을 발견하게 만들어 상담의 가치를 높임

---

## 카테고리 2. 포트폴리오 설명 및 시각화

---

**[FP-03] 자산 포트폴리오 쉬운 언어 설명**
도메인: 재무설계
용도: 복잡한 포트폴리오 구성을 고객이 이해하기 쉽게 설명
프롬프트:
```
---
아래 포트폴리오를 금융 비전문가인 고객에게 설명하는 글을 작성해주세요.

포트폴리오 구성:
- 안전자산: [금액 또는 비율] (예금, 채권 등)
- 투자자산: [금액 또는 비율] (주식, 펀드 등)
- 보장자산: [금액 또는 비율] (보험)
- 유동자산: [금액 또는 비율] (비상금)
고객 목표: [목표 내용]
투자 성향: [안정형 / 안정추구형 / 중립형 / 적극투자형]

작성 조건:
1. "왜 이렇게 구성했는가"를 고객 목표와 연결해서 설명
2. 각 자산군을 비유(예: 안전자산 = 우산)로 설명
3. 예상 시나리오(좋을 때/보통일 때/나쁠 때) 3가지 포함
4. 300자 이내 요약 + 상세 설명 구조로 작성
---
```
효과적인 이유: 비유와 시나리오를 활용해 고객이 자신의 포트폴리오를 직관적으로 이해하고 신뢰하게 만듦

---

**[FP-04] 포트폴리오 리밸런싱 설명 스크립트**
도메인: 재무설계
용도: 포트폴리오 조정 필요성을 고객에게 납득시키는 설명 자료
프롬프트:
```
---
고객에게 포트폴리오 리밸런싱을 제안해야 합니다.

현재 상황:
- 기존 포트폴리오: [구성 내용]
- 현재 시장 상황: [시장 변화 내용]
- 변경 후 포트폴리오: [구성 내용]
- 변경 이유: [이유]

아래 순서로 고객 설명 스크립트를 작성해주세요.
1. 현재 포트폴리오의 좋은 점 인정 (고객 감정 배려)
2. 변화가 필요한 이유 (시장/고객 상황 변화)
3. 새 구성의 장점 (숫자 포함)
4. 예상 리스크와 대응 방안
5. 고객 동의를 자연스럽게 이끄는 클로징 멘트

전체 구어체로, 상담 현장에서 바로 읽을 수 있게 작성해주세요.
---
```
효과적인 이유: 변경에 대한 고객의 불안을 단계적으로 해소하면서 신뢰 기반 의사결정을 유도함

---

## 카테고리 3. 재무 리포트 작성 (고객용)

---

**[FP-05] 고객용 연간 재무 현황 리포트**
도메인: 재무설계
용도: 1년간의 재무 변화를 고객이 이해하기 쉬운 리포트로 정리
프롬프트:
```
---
아래 데이터를 바탕으로 고객에게 전달할 연간 재무 현황 리포트를 작성해주세요.

고객 정보: [나이, 가족구성, 직업]
1년 전 자산 현황: [내용]
현재 자산 현황: [내용]
올해 달성한 재무 목표: [내용]
미달성 항목: [내용]
내년 주요 재무 이벤트: [내용]

리포트 구성:
1. 표지 문구 (고객 이름 포함, 따뜻한 톤)
2. 올해 재무 요약 (잘한 점 3가지 강조)
3. 자산 변화 표 (전년 대비)
4. 목표 달성률 시각화 (텍스트 형태로 표현)
5. 내년 집중 과제 3가지
6. 담당 FP 코멘트 (개인화된 응원 메시지)

전문적이되 따뜻하고 읽기 쉬운 문체로 작성해주세요.
---
```
효과적인 이유: 숫자 중심이 아닌 고객의 성취를 부각하는 구성으로 재계약 및 관계 유지에 효과적

---

**[FP-06] 재무 진단 요약 보고서 (상담 후)**
도메인: 재무설계
용도: 첫 상담 후 고객에게 보내는 재무 진단 요약본 작성
프롬프트:
```
---
오늘 첫 재무 상담을 마쳤습니다. 상담 내용을 바탕으로 고객에게 보낼 재무 진단 요약 보고서를 작성해주세요.

상담 내용 메모: [상담 내용 요약 입력]

보고서 구성:
1. 고객님의 재무 현황 한눈에 보기 (강점 2개, 보완점 2개)
2. 가장 시급한 재무 과제 (우선순위 순)
3. 추천 솔루션 개요 (아직 구체적 상품명 없이 방향성만)
4. 다음 상담에서 논의할 내용
5. 담당자 연락처 및 마무리 인사

A4 1장 분량, 고객이 가족과 공유하기 좋은 깔끔한 형태로 작성해주세요.
---
```
효과적인 이유: 상담 직후 고객에게 전달하면 전문성을 각인시키고 다음 상담 약속을 자연스럽게 유도함

---

## 카테고리 4. 위험 성향 분석

---

**[FP-07] 투자 성향 분석 결과 해석 및 설명**
도메인: 재무설계
용도: 투자 성향 설문 결과를 고객에게 의미 있게 설명
프롬프트:
```
---
고객의 투자 성향 설문 결과를 분석하고 맞춤 설명을 작성해주세요.

설문 결과: [안정형 / 안정추구형 / 위험중립형 / 적극투자형 / 공격투자형]
고객 나이: [나이]
주요 재무 목표: [내용]
설문 주요 응답 패턴: [특이사항 메모]

작성 내용:
1. 성향 유형 설명 (이 유형의 특징과 심리)
2. 이 성향이 고객의 목표에 미치는 영향 (긍정/주의사항)
3. 성향에 맞는 자산 배분 원칙 (%)
4. 이 성향의 고객이 자주 하는 실수와 예방법
5. 고객에게 전달하는 공감 멘트 (성향을 존중하는 표현)

전문적이지만 고객이 "맞아, 내 이야기야"라고 느낄 수 있는 언어로 작성해주세요.
---
```
효과적인 이유: 성향 분석을 고객의 자기이해와 연결시켜 상품 추천에 대한 신뢰와 수용도를 높임

---

**[FP-08] 성향과 목표 불일치 시 조율 대화 스크립트**
도메인: 재무설계
용도: 고객의 투자 성향과 재무 목표가 충돌할 때 현실적 대화 유도
프롬프트:
```
---
고객의 투자 성향과 목표 사이에 불일치가 발생했습니다.

상황:
- 고객 성향: [예: 안정형]
- 고객 목표: [예: 10년 후 5억 원 자산 형성]
- 현재 자산: [금액]
- 예상 수익률 갭: [목표 달성에 필요한 수익률 vs 성향에 맞는 예상 수익률]

아래를 작성해주세요.
1. 현실적 시뮬레이션 비교 (성향대로 vs 목표 달성에 필요한 방식)
2. 고객이 선택할 수 있는 3가지 옵션 제시
3. 각 옵션의 trade-off 설명
4. 고객의 결정을 존중하면서 최선의 방향을 안내하는 대화 스크립트

고객이 스스로 현실적인 선택을 하도록 돕는 코칭 방식으로 작성해주세요.
---
```
효과적인 이유: 설계사가 일방적으로 설득하지 않고 고객 스스로 판단하게 하여 나중의 불만을 예방함

---

## 카테고리 5. 노후 설계 시나리오

---

**[FP-09] 은퇴 시나리오 3단계 설계**
도메인: 재무설계
용도: 고객의 은퇴 준비 현황을 진단하고 3가지 시나리오로 미래를 시각화
프롬프트:
```
---
고객의 은퇴 준비 시나리오를 작성해주세요.

고객 정보:
- 현재 나이: [나이] / 희망 은퇴 나이: [나이]
- 현재 월 소득: [금액] / 월 저축 가능액: [금액]
- 현재 노후 준비 자산: [금액] (국민연금, 퇴직금, 개인연금 등 구분)
- 희망 은퇴 후 월 생활비: [금액]
- 예상 수명: [나이] (또는 기대수명 사용)

시나리오 3가지 작성:
1. 현재 그대로 유지할 경우 (낙관/현실/비관 수치 포함)
2. 지금부터 [월 추가저축액] 더 준비할 경우
3. 최적 노후 목표 달성을 위한 권장 플랜

각 시나리오에 월 수령액, 준비 부족액, 필요 행동을 포함하고
고객이 위기감과 희망을 동시에 느낄 수 있는 서술 방식으로 작성해주세요.
---
```
효과적인 이유: 세 가지 시나리오 비교가 고객 스스로 "지금 행동해야 한다"는 동기를 유발함

---

**[FP-10] 은퇴 후 지출 계획 설계**
도메인: 재무설계
용도: 은퇴 후 생활비를 항목별로 현실적으로 설계
프롬프트:
```
---
고객의 은퇴 후 지출 계획을 설계해주세요.

고객 정보:
- 은퇴 예정 나이: [나이]
- 거주 지역: [지역]
- 가족 구성 (은퇴 시점 기준): [구성]
- 희망 라이프스타일: [예: 국내여행 월 1회, 취미생활, 의료비 여유 있게]

지출 계획 구성:
1. 필수 지출 (주거, 식비, 의료, 공과금)
2. 선택 지출 (여가, 취미, 여행)
3. 비정기 지출 (자녀 경조사, 손자녀 관련, 의료 목돈)
4. 인플레이션 반영 (은퇴 후 20년 기준 물가 상승 적용)
5. 연령대별 지출 변화 패턴 (60대/70대/80대 이후)

표 형태 + 설명 형태로 작성하고, 현실적이면서도 풍요로운 노후의 그림을 그려주세요.
---
```
효과적인 이유: 막연한 노후가 아닌 구체적 생활 그림으로 고객의 준비 의지를 높임

---

## 카테고리 6. 세금·절세 관련 설명 자료

---

**[FP-11] 절세 전략 고객 설명 자료**
도메인: 재무설계
용도: 고객이 놓치고 있는 절세 방법을 쉽고 실용적으로 안내
프롬프트:
```
---
아래 고객 상황에 맞는 절세 전략 설명 자료를 작성해주세요.

고객 정보:
- 직업/소득 유형: [직장인 / 자영업자 / 프리랜서]
- 연소득: [금액]
- 주요 관심사: [예: 연말정산 환급, 금융소득 절세, 부동산 세금]
- 현재 활용 중인 절세 수단: [내용 또는 없음]

작성 내용:
1. 이 고객이 즉시 활용 가능한 절세 방법 TOP 5 (우선순위 순)
2. 각 방법의 예상 절세 금액 (대략적 추정)
3. 실행 방법 및 주의사항
4. 놓치면 손해인 세금 캘린더 (월별 신청/납부 일정)
5. 전문가 상담이 필요한 경우 (자가 처리 한계점)

법적 근거를 간략히 포함하되, 전문용어 없이 이해하기 쉽게 작성해주세요.
```

```
질문은 아래 기준으로 구성해 주세요:

```

```
당신은 시니어 프로덕트 매니저(PM)입니다.

아이디어 및 질의응답 내용: [내용 붙여넣기]

PRD 구성 항목:
```

**[BS-04] 사업계획서 핵심 섹션 작성 (문제-솔루션-시장)**

```

해결하는 문제: [내용]
솔루션: [내용]
시장 규모 데이터: [있으면 입력]

Section 1: 문제 정의
- 문제의 실재성과 심각성 (고객의 고통 서술)
- 현재 대안의 한계 (왜 기존 방법이 부족한가)
- 이 문제를 해결해야 하는 긴박성

- 고객이 얻는 구체적 가치 (수치화)

Section 3: 시장 기회
- TAM / SAM / SOM 추정 방법론
- 시장 트렌드와 진입 타이밍의 당위성
- 초기 타겟 세그먼트 집중 전략

투자자가 "이건 된다"고 느끼게 하는 논리와 언어로 작성해주세요.
---
```
효과적인 이유: 문제-솔루션-시장의 논리적 연결이 투자자 설득의 핵심이며, 이 흐름이 자연스러울수록 신뢰가 높아짐

---

## 카테고리 3. OKR/KPI 설계

---

**[BS-05] 조직/팀 OKR 설계**
도메인: 경영전략
용도: 팀이나 사업부 단위의 OKR(목표-핵심결과)을 실전에 맞게 설계
프롬프트:
```
---
아래 조직을 위한 분기 OKR을 설계해주세요.

조직 정보: [팀명, 인원, 주요 기능]
상위 경영 목표: [회사 전체 목표]
이번 분기 중점 과제: [내용]
주요 고객/이해관계자: [내용]
전분기 주요 성과와 미달 항목: [내용]

OKR 설계:
- Objective 1~3개 작성 (도전적이고 영감을 주는 목표 서술)
- 각 Objective당 Key Results 3~4개 (측정 가능한 숫자/결과 중심)
- 각 KR의 현재 수준 (0점) vs 목표 수준 (1점)
- KR 달성 여부를 판단하는 측정 방법
- 실패했을 때 학습할 내용 (실패 허용 기준)

도달 가능하면서도 스트레치 목표가 되도록, 70% 달성 시 성공인 기준으로 설계해주세요.
---
```
효과적인 이유: 도전적 목표와 측정 가능한 결과의 조합이 팀의 집중력과 실행 에너지를 높임

---

**[BS-06] 부서별 KPI 체계 설계**
도메인: 경영전략
용도: 각 부서의 역할에 맞는 KPI를 체계적으로 설계하여 성과 관리 기반 수립
프롬프트:
```
---
아래 부서의 KPI 체계를 설계해주세요.

부서: [부서명]
부서의 주요 역할과 책임: [내용]
회사 전체 목표와의 연결: [내용]
현재 측정하고 있는 지표 (있다면): [내용]
KPI 활용 목적: [성과 평가 / 업무 개선 / 보상 연계]

KPI 설계:
1. 결과 KPI (Lagging Indicator): 최종 성과 측정 지표 3~5개
2. 과정 KPI (Leading Indicator): 결과를 예측하는 활동 지표 3~5개
3. 각 KPI의 측정 방법, 주기, 목표치 설정 방법
4. KPI 간 충돌 가능성과 우선순위
5. 이 KPI 체계의 한계와 보완 방법

"측정이 쉬운 것"이 아닌 "중요한 것을 측정"하는 관점으로 설계해주세요.
---
```
효과적인 이유: 결과 지표와 과정 지표를 구분함으로써 사후 평가가 아닌 사전 관리가 가능해짐

---

```
---
아래 경쟁사에 대한 심층 분석을 실시해주세요.

분석 대상 경쟁사: [회사명]
분석 목적: [차별화 전략 수립 / 영업 대응 / M&A 검토 등]
활용 가능한 공개 정보: [재무제표, 언론보도, 홈페이지, 고객 후기 등]

분석 구성:
1. 경쟁사 사업 모델 분석 (수익 구조, 핵심 고객, 가치 제안)

```
효과적인 이유: 과거 데이터 분석을 넘어 경쟁사의 미래 행동 예측까지 포함해 선제적 대응 전략 수립이 가능함

## 카테고리 5. 전략 방향 도출

---

**[BS-09] Porter의 5 Forces 분석**
도메인: 경영전략
용도: 산업의 구조적 매력도를 5가지 힘으로 분석해 전략적 포지셔닝 결정
프롬프트:
```
---
아래 산업에 대한 Porter의 5 Forces 분석을 실시하고 전략적 시사점을 도출해주세요.

분석 산업: [산업명]
분석 관점: [현재 사업자 / 신규 진입자]
현재 경쟁 구도: [주요 정보 입력]

5 Forces 분석:
1. 기존 경쟁자 간 경쟁 강도 (시장 집중도, 가격 경쟁, 제품 차별화)
2. 신규 진입 위협 (진입 장벽, 규모의 경제, 브랜드 충성도)
3. 대체재 위협 (대체재 존재 여부, 전환 비용, 고객 성향)
4. 구매자 교섭력 (집중도, 전환 비용, 가격 민감도)
5. 공급자 교섭력 (공급자 집중도, 대체 공급원, 전방통합 가능성)

종합 분석:
- 각 힘의 강도 평가 (강/중/약) + 근거
- 이 산업의 전체 매력도 점수 (5점 만점)
- 이 구조에서 살아남는 전략 3가지
- 가장 급하게 대응해야 할 위협 요인
---
```
효과적인 이유: 산업 구조를 5개 차원으로 분해하면 본능적 판단이 아닌 구조적 근거를 가진 전략이 만들어짐

---

**[BS-10] BCG 매트릭스 포트폴리오 분석**
도메인: 경영전략
용도: 사업/제품 포트폴리오를 BCG 매트릭스로 분석해 자원 배분 전략 수립
프롬프트:
```
---
우리 회사의 사업/제품 포트폴리오를 BCG 매트릭스로 분석하고 자원 배분 전략을 제안해주세요.

사업/제품 목록: [목록]
각 사업의 시장 성장률: [데이터 또는 추정]
각 사업의 시장 점유율 (상대적): [데이터 또는 추정]
현재 각 사업에 대한 투자 수준: [내용]

분석 구성:
1. 각 사업의 BCG 포지션 분류 (Star / Cash Cow / Question Mark / Dog) + 근거
2. 포지션별 전략 권고
   - Star: 투자 유지/확대 전략
   - Cash Cow: 수익 극대화 및 효율화 전략
   - Question Mark: 투자 vs 철수 결정 기준
   - Dog: 유지 vs 매각/철수 전략
3. 전체 포트폴리오 밸런스 진단
4. 향후 3년 자원 재배분 시나리오
5. BCG 분석의 한계와 보완 관점

현재 자원을 어디에 집중해야 하는지 명확한 우선순위로 제시해주세요.
---
```
효과적인 이유: 포트폴리오 전체를 한눈에 보는 틀이 자원 배분의 감이 아닌 논리를 제공함

---

**[BS-11] 전략적 의사결정 분석 프레임**

```
---
아래 경영 의사결정에 대한 체계적 분석을 해주세요.

결정해야 할 사항: [내용]
결정 배경과 맥락: [내용]
검토 중인 선택지: [선택지 A, B, C 등]
결정 기한: [날짜]
핵심 이해관계자: [내용]
중요 제약 조건: [예산, 인력, 규제 등]

분석 프레임:
1. 결정의 핵심 질문 명확화 (진짜 결정해야 할 것이 무엇인가)
2. 각 선택지의 장단점 분석 (동일한 기준으로)
3. 각 선택지의 Best/Expected/Worst 시나리오

5. 추천 선택지와 근거
6. 선택 후 리스크 완화 방안

"나중에 이 결정을 후회하지 않을 것인가"를 기준으로 분석해주세요.
---
```
효과적인 이유: 감이 아닌 기준 매트릭스로 선택하게 함으로써 결정 후 후회와 조직 내 설득 모두를 용이하게 함

---

**[BS-12] 경영 딜레마 해결 (두 가지 선택의 갈등)**
도메인: 경영전략
용도: 명확한 정답이 없는 경영 딜레마를 다각도에서 사고하는 구조 제공
프롬프트:
```
---
아래 경영 딜레마를 분석하고 해결 방향을 제안해주세요.

딜레마 상황: [예: 단기 수익성 vs 장기 성장 투자, 직원 감원 vs 비용 증가 감수]
현재 상황과 압박 요인: [내용]
각 선택이 가져올 결과에 대한 나의 가정: [내용]
과거 유사한 상황: [있으면 입력]

분석 구성:
1. 딜레마의 본질 파악 (진짜 갈등이 무엇인가)
2. 각 선택의 단기/장기 영향 분석

---
```
효과적인 이유: 딜레마를 이분법이 아닌 제3의 옵션 탐색으로 접근함으로써 창의적 해결책을 발견할 가능성을 높임

```
사업 내용: [내용]

현재 인식하고 있는 주요 리스크: [내용]

리스크 분석 구성:
1. 리스크 카테고리별 식별
   - 시장 리스크 (수요 변화, 경쟁, 가격)

5. 리스크 모니터링 체계 제안

"알려진 리스크"뿐 아니라 "알지 못하는 리스크"까지 발굴하려는 시도를 포함해주세요.
---
```
효과적인 이유: 발생 가능성과 영향도의 매트릭스가 제한된 자원을 가장 중요한 리스크에 집중하게 만듦

---

**[BS-14] 시나리오 플래닝 (불확실성 대비 전략)**
도메인: 경영전략
용도: 미래 불확실성에 대비한 복수 시나리오별 전략을 수립
프롬프트:
```
---
아래 상황에 대한 시나리오 플래닝을 수행해주세요.

현재 사업 상황: [내용]
가장 큰 불확실성 요인 2가지: [내용]
계획 기간: [1년 / 3년 / 5년]
주요 의사결정: [어떤 결정에 이 분석이 필요한지]

시나리오 설계:
1. 2×2 시나리오 매트릭스 설계 (핵심 불확실성 2개로 4개 시나리오 구성)
2. 각 시나리오 서술 (이름 + 세계관 + 우리 사업에의 영향)
3. 시나리오별 전략 대응
   - Best Case: 기회 극대화 전략
   - Base Case: 현실적 성장 전략
   - Downside Case: 방어 및 생존 전략
   - Wild Card: 극단적 변화 대응
4. 어떤 시나리오에서도 유효한 "Robust Strategy" 도출
5. 조기 경보 지표 (어떤 신호가 보이면 전략을 전환할 것인가)

```


효과적인 이유: 투자자가 물어볼 질문을 미리 준비하는 구조가 실제 IR 미팅의 성공률을 높임
