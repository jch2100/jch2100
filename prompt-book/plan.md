### O2: 확장 가능한 아키텍처
> "프롬프트 → 스킬 → 플러그인 3단계"

| KR | 내용 | 현황 |
|----|------|------|
| 2.1 | 3단계 확장 로드맵 정의 | 완료 |
| 2.2 | HTML 라이브러리 기술 구현 리서치 | 완료 (2026-03-22) |
| 2.3 | HTML 라이브러리 UI 프로토타입 | 미착수 |

**HTML 구현 7단계 로드맵:**

| 단계 | 내용 | 세션 |
|------|------|------|
| 1 | HTML 껍데기 + 수동 CSS (아이보리 팔레트) | 1세션 |
| 2 | JSON 데이터 구조 확정 + 더미 데이터 5개 | 1세션 |
| 3 | JS 카드 렌더링 (DOM 생성) | 1세션 |
| 4 | 사이드바 카테고리 필터 | 1세션 |
| 5 | 검색 기능 | 0.5세션 |
| 6 | 복사 버튼 + 변수(`{산업}`) 하이라이트 | 0.5세션 |
| 7 | 모바일 반응형 | 1세션 |

> 각 단계가 독립적으로 완결됨. 중단해도 이전 단계는 그대로 동작.

**기술 결정 사항 (변경 불가):**
- CSS: Tailwind CDN 사용 안 함 → 수동 CSS `<style>` 태그
- 데이터: 외부 JSON fetch 안 함 → 인라인 `const PROMPTS = [...]`
- JS: 프레임워크 없음 → Vanilla JS
- 이유: 오프라인 + 단일 HTML 파일 조건 충족
