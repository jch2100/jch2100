### 기능 요구사항

| 기능 | 우선순위 | 설명 |
|------|---------|------|
| 십진분류 네비게이션 | 필수 | 좌측 사이드바, 펼치기/접기 |
| 원클릭 복사 | 필수 | 프롬프트 텍스트 클립보드 복사 |
| 검색 | 필수 | 키워드/도메인/태그 통합 검색 |
| 도메인 키워드 사전 | 높음 | 모르는 용어 즉시 확인 |
| 변수 하이라이트 | 높음 | {산업}, {역할} 등 변수 표시 |
| 모바일 반응형 | 높음 | 수업 현장에서 폰으로 사용 |
| 다크모드 | 낮음 | 선택 사항 |
| 즐겨찾기 | 낮음 | 로컬스토리지 기반 |

### 기술 스택 (예정)

- **단일 HTML 파일** — 서버 불필요, 오프라인 사용 가능
- **Tailwind CSS (CDN)** — 빠른 스타일링
- **Vanilla JS** — 프레임워크 없이 가볍게
- **JSON 데이터 내장** — 프롬프트 데이터를 HTML 내 JSON으로
