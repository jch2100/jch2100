## 1. 가장 많이 오해되는 개념: Lead

### "Lead를 만들어라"는 말의 문제

한국 IT 영업에서 "Lead 생성"은 관용적으로 쓰이지만,
실제로 그들이 원하는 것은 **Lead가 아니라 Opportunity**인 경우가 대부분이다.

Lead는 아직 자격 검증이 되지 않은 초기 관심자다.
그것을 Opportunity로 키우는 과정 전체를 뭉뚱그려 "Lead 만들기"라 부르는 것은
퍼널의 입구와 출구를 혼동하는 것이다.

### 단계 정의 (Lead → 고객)

| 단계 | 정의 | 주체 |
|------|------|------|
| **Lead** | 뉴스레터 구독, 폼 제출 등 초기 관심 표현. 자격 미검증 | 없음(자동) |
| **MQL** (Marketing Qualified Lead) | 마케팅이 행동 데이터로 "구매 가능성 있음" 판단한 Lead | 마케팅 |
| **SAL** (Sales Accepted Lead) | 영업팀이 MQL을 검토 후 "후속 연락할 가치 있음" 승인 | 영업(수용) |
| **SQL** (Sales Qualified Lead) | 영업이 직접 확인. 예산·권한·필요·일정이 확인된 상태 | 영업 |
| **Prospect** | SQL 중 발견 콜(Discovery Call)을 마친 고객 | 영업 |
| **Opportunity** | 구매 의사 + BANT 조건이 충족된 딜(Deal) | 영업 |
| **Customer** | 계약 완료 | 영업/CS |

> 핵심: MQL → SQL 전환율은 업계 평균 **13%**. 모든 Lead가 SQL이 되지 않는다.

## 2. 퍼널(Funnel) vs 파이프라인(Pipeline)

반드시 구분해야 하는 두 개념.

| 구분 | Funnel (깔때기) | Pipeline (파이프라인) |
|------|---------------|-------------------|
| 관점 | 마케팅 (구매자 여정) | 영업 (영업 프로세스) |
| 질문 | "얼마나 많은 사람이 각 단계에 있나?" | "각 딜이 지금 어느 단계인가?" |
| 목적 | 전환율 측정, 리드 볼륨 관리 | 딜 진행 상황 관리, 매출 예측 |
| 단계 | Awareness → Interest → Evaluation → Action | Prospecting → Qualification → Pitch → Negotiation → Close |

> "퍼널이 건강해야 파이프라인이 채워진다."

### ToFU / MoFU / BoFU (Funnel 위치)
- **ToFU** (Top of Funnel): 인지 단계. 블로그, 광고, SNS
- **MoFU** (Middle of Funnel): 고려 단계. 웨비나, 케이스 스터디
- **BoFU** (Bottom of Funnel): 구매 결정 단계. 데모, 가격 협의

## 3. 리드 자격검증 프레임워크

### BANT (IBM, 1960s — 가장 보편적)

| 항목 | 질문 |
|------|------|
| **B**udget | 우리 제품을 구매할 예산이 있는가? |
| **A**uthority | 이 사람이 실제 결정권자인가? |
| **N**eed | 우리 제품으로 해결할 진짜 문제가 있는가? |
| **T**imeline | 언제 도입할 계획인가? |

**BANT의 한계:** 판매자 중심. 고객이 뭘 필요로 하는지보다 "내가 팔 수 있냐"에 집중.
현대 B2B에서는 **N → A → B → T** 순서로 재배열해 사용하는 추세.

---

### BANTCH (무패영업, 강민호 — BANT 확장)

BANT에 두 가지 추가:

| 항목 | 의미 |
|------|------|
| **C**hampion | 고객사 내부에서 우리 편이 되어 주는 사람. 의사결정 구조를 알려주는 내부 조력자 |
| **H** | 도입 장벽(Hurdle) 또는 구매 이력(History). 버전마다 해석 다름 |

> Champion 확보가 복잡계 B2B 영업의 핵심. MEDDIC의 Champion 개념과 동일.

---

### MEDDIC / MEDDPICC (엔터프라이즈 영업 표준)

1996년 PTC에서 개발. 연매출을 3억 달러 → 10억 달러로 성장시킨 방법론.

| 항목 | 의미 |
|------|------|
| **M**etrics | 우리 솔루션의 ROI를 수치로 표현. "몇 % 비용 절감?" |
| **E**conomic Buyer | 예산 집행 최종 결정권자. Champion과 다른 사람일 수 있음 |
| **D**ecision Criteria | 고객이 솔루션 선택 시 사용하는 평가 기준 |
| **D**ecision Process | 구매 결정이 내려지는 내부 프로세스 순서 |
| **I**dentify Pain | 비즈니스에 실질적 타격을 주는 핵심 문제 |
| **C**hampion | 조직 내 권한·영향력 있는 내부 지지자 |
| **+P** Paper Process | 법무·보안·구매 등 계약 전 행정 절차 (MEDDPICC) |
| **+C** Competition | 같은 예산을 두고 경쟁하는 다른 벤더/옵션 (MEDDPICC) |

> MEDDIC은 딜 크기별로 선택: $50K 이하 → BANT, $250K 이상 → MEDDPICC

## 4. 판매 방법론

### SPIN Selling (Neil Rackham, 1988)

35,000건 세일즈 콜 분석. 복잡한 B2B 세일즈에서 탑 영업의 질문 패턴 발견.

| 질문 유형 | 목적 | 예시 |
|---------|------|------|
| **S**ituation | 현재 상황 파악 | "현재 어떤 방식으로 영업 관리하고 계세요?" |
| **P**roblem | 문제/불편 발굴 | "어떤 부분에서 가장 어려움을 느끼세요?" |
| **I**mplication | 문제가 계속될 경우 파급효과 | "그 문제로 인해 팀 성과에 어떤 영향이 있나요?" |
| **N**eed-payoff | 해결했을 때 가치 | "만약 그 문제가 해결된다면 어떤 변화가 생길까요?" |

> 핵심: 탑 영업은 Situation 질문을 최소화하고 Implication·Need-payoff에 집중한다.

---

### FABE (제품 프레젠테이션)

MBA 영업 과목의 기본. 제품 설명을 고객 가치로 연결하는 구조.

| 항목 | 의미 | 예시 |
|------|------|------|
| **F**eature | 제품의 특징/기능 | "AI 기반 통화 분석 기능" |
| **A**dvantage | 경쟁 대비 우위 | "실시간 분석으로 다른 솔루션보다 3배 빠름" |
| **B**enefit | 고객이 얻는 구체적 이익 | "영업팀이 코칭 없이도 자가진단 가능" |
| **E**vidence | 증거 (수치, 사례, 후기) | "A사 도입 후 성약률 23% 향상" |

---

### Challenger Sale (CEB/Gartner, 2011)

40%의 고성과 영업은 "Challenger 유형". 고객의 현재 생각을 흔들고 새 관점을 제시.

| 핵심 개념 | 설명 |
|---------|------|
| **Commercial Teaching** | 고객이 미처 몰랐던 비즈니스 문제를 먼저 가르침 |
| **Reframe** | 문제를 새로운 시각으로 재정의 |
| **Constructive Tension** | 현 상태(Status Quo)가 위험하다는 건설적 긴장감 조성 |
| Teach → Tailor → Take Control | Challenger의 3단계 행동 원칙 |

---

### Consultative Selling (상담형 영업)

제품을 파는 것이 아니라 **문제를 진단하고 함께 해결책을 설계**하는 방식.

핵심 키워드: Trusted Advisor / Pain Points / Needs Diagnosis / Co-creation / Active Listening

---

### Value-Based Selling (가치 기반 영업)

가격이 아닌 **ROI와 비즈니스 임팩트**로 설득.

핵심 키워드: Value Proposition / ROI / Business Outcome / TCO (Total Cost of Ownership) / Quantified Value

## 5. CRM / 영업 운영 키워드

| 용어 | 정의 |
|------|------|
| **ICP** (Ideal Customer Profile) | 우리 제품에 가장 잘 맞는 고객 유형 정의 |
| **Persona** | ICP 내 구체적 구매 담당자 프로필 |
| **Cadence** | 영업 접촉 주기와 채널 조합 (예: 이메일→콜→LinkedIn 순서) |
| **Velocity** | 딜이 파이프라인을 통과하는 속도 |
| **Win Rate** | 기회(Opportunity) 대비 성약 비율 |
| **ACV** (Annual Contract Value) | 연간 계약 금액 |
| **ARR** (Annual Recurring Revenue) | 연간 반복 매출 (SaaS에서 핵심 지표) |
| **Churn** | 기존 고객 이탈 |
| **NRR** (Net Revenue Retention) | 기존 고객 매출 유지율 (업셀/다운셀 포함) |
| **Sales Cycle** | 첫 접촉부터 계약까지 평균 소요 기간 |
| **Quota** | 개별 영업 담당자의 매출 목표 |
| **Outbound** | 영업이 먼저 접근 (콜드콜, 이메일) |
| **Inbound** | 고객이 먼저 관심 표현 (문의, 가입) |
| **SDR** (Sales Development Rep) | 아웃바운드 리드 발굴 담당 (자격검증 전) |
| **BDR** (Business Development Rep) | 신규 시장/파트너 개척 담당 |
| **AE** (Account Executive) | SQL 이후 딜 클로징 담당 영업 |
| **CSM** (Customer Success Manager) | 계약 후 고객 성공 관리 |
| **Upsell / Cross-sell** | 기존 고객에게 더 비싼/다른 제품 추가 판매 |

## 6. 영업 접근법 키워드 (프롬프트 작성 시 활용)

| 개념 | 설명 |
|------|------|
| **Cold Call** | 사전 관계 없이 전화로 첫 접촉 |
| **Warm Call** | 사전 접점(이벤트, 콘텐츠)이 있는 상태의 전화 |
| **Social Selling** | LinkedIn 등 SNS로 관계 형성 후 영업 |
| **Account-Based Selling** | 특정 전략 고객사에 집중적으로 접근 |
| **SPIN 질문** | 상황→문제→파급→가치 순 질문 설계 |
| **Discovery Call** | 고객 니즈와 상황을 파악하는 초기 미팅 |
| **Demo** | 제품/서비스 시연 |
| **Proof of Concept (PoC)** | 소규모 파일럿 테스트로 가치 증명 |
| **RFP** (Request for Proposal) | 고객의 공식 제안요청서 |
| **Objection Handling** | 고객 반대 의견 대응 기술 |
| **Closing Technique** | 계약으로 마무리하는 기술 (Assumptive, Urgency 등) |
| **Follow-up** | 미팅/제안 후 지속 연락 |
| **Stakeholder Mapping** | 구매 관여자 전체 파악 및 영향력 분석 |
