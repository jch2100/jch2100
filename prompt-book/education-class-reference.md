# AI 에이전트 교육 클래스 — 레퍼런스

## 출처
이승필 강사 / (주)사용성연구소 — "AI 에이전트, 4주면 만든다" 시즌 2

## 핵심 포지셔닝
- 타깃: 코딩 모르는 비개발자 (대표, 사내 AI 담당자, 자동화 희망자)
- 차별화: 화려한 약속 대신 시행착오 + 실전 노하우
- 규모: 소수정예 최대 10명, 오프라인
- 장소: 코엑스 스파크플러스
- 일정: 매주 토요일 오전 10시–오후 1시, 4주 (총 12시간)
- 수강료: 80만원 (정가 100만원, 20% 할인)

## 4주 커리큘럼

### Week 01 — 클로드 코드 세팅 & CLAUDE.md 설계
- 환경 설정 (Node.js, CLI)
- 클로드 코드 설치 및 첫 실행
- 기본 명령어 익히기
- CLAUDE.md 실전 설계
- 첫 번째 에이전트 대화 실습
- 핵심: 설치부터 CLAUDE.md 작성까지 첫 날 완성

### Week 02 — 스킬 파일 구조 & 단일 에이전트 구축
- 스킬 파일 구조 잡기
- 하네스 엔지니어링
- 나만의 단일 에이전트 구축
- 실전 업무에 적용
- 에이전트 테스트 & 반복 개선

### Week 03 — 멀티 에이전트 & 실전 배포
- 서브에이전트 아키텍처 이해
- 오케스트레이터 설계
- 에이전트 간 협업 구조
- Openclaw 연동
- GitHub 업로드 & Vercel 배포

### Week 04 — 실전 프로젝트 발표 & 피드백
- 나만의 실전 프로젝트 완성
- 최종 발표 및 동료 피드백
- 수료 & 우수 프로젝트 시상
- 1위 30만원 / 2위 20만원 / 3위 10만원 수업료 페이백

## As-is → To-be 변화 약속
| As-is | To-be |
|-------|-------|
| 뭐부터 해야 할지 모른다 | 클로드 코드 열고 에이전트에게 업무 지시 |
| 프롬프트 결과가 매번 다르다 | CLAUDE.md로 일관된 결과 |
| 개발자 없이는 자동화 불가 | 코딩 없이 에이전트 직접 구축 |
| 반복 업무에 시간 빼앗김 | 에이전트가 반복 업무 처리 |
| 혼자서는 한계 | 멀티 에이전트 팀이 협업 |
