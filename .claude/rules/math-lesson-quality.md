# 수학 학습지 레슨 작성 규칙

## 순서 원칙

반드시 이 순서로 작성한다.

1. 실생활 질문 먼저
2. 직관적 설명
3. 수식/공식
4. 연습 문제

공식이 질문보다 먼저 나오면 "학교 수학"이 된다.

## 인용 원칙

- 모든 연구 인용에 저자명 + 연도 필수
- 작성 후 반드시 `/lesson-review`로 사실 검증
- "연구에 따르면" 같은 출처 없는 표현 금지

## 수식 원칙

- 수식은 개념 설명 후에만 등장
- 변수는 반드시 정의한다 (R: 기억 보존율 등)
- 계산 결과는 검산한다

## 심리학-수학 연결 원칙

두 분야를 연결할 때 반드시 명시적 문장으로 표현한다.

좋은 예: "이것이 수학적으로 표현하면 ○○이다"
나쁜 예: 심리학 설명 → 수식 (연결 없이 나열)

## 완성 전 필수 절차

1. HARNESS.md 12개 항목 체크
2. `/lesson-review [파일경로]` 실행
3. 자기 설명 테스트 (작성자 직접 수행)

이 세 가지를 거치지 않은 레슨은 완성으로 보지 않는다.
