# 프롬프트 작성 규칙

## 필수 구성 요소

모든 프롬프트에는 다음 5가지가 있어야 함:

1. **번호** — 분류체계 기반 (예: #101, #201)
2. **역할 부여** — "당신은 {도메인} 전문가입니다"로 시작
3. **도메인 키워드** — 최소 2개 이상의 전문 용어
4. **출력 형식** — 목록/표/단락 등 명시
5. **논문/경험 근거** — 1줄 이상의 출처 태깅

## 프롬프트 파일 포맷

각 md 파일은 다음 구조를 따름:

```markdown
## #번호 제목
**근거**: 출처 (연도)
**역할**: ○○ 전문가
**난이도**: 초급/중급/고급
**키워드**: [키워드1] [키워드2]

---
프롬프트 본문
---

**강사 팁**: 경험 코멘트
```

## 금지 사항

- 브레인스토밍 프롬프트에 예시 포함 금지
- 근거 없이 프롬프트 추가 금지
- 한 번의 요청으로 완결되지 않는 멀티턴 프롬프트는 주의 표시
- 수익화 관련 내용은 어디에도 추가 금지
