# 프롬프트 품질 검토 스킬

## 검토 기준
각 프롬프트를 다음 5가지 기준으로 평가:

1. **근거 여부** — 논문/경험 출처가 있는가?
2. **역할 부여** — 도메인 전문가 역할이 명확한가?
3. **도메인 키워드** — 전문 용어가 포함되어 있는가?
4. **출력 형식** — 원하는 출력 형식을 명시했는가?
5. **싱글턴 원칙** — 한 번의 요청으로 완결되는가?

## 등급 기준
- **A급**: 5개 모두 충족
- **B급**: 3~4개 충족, 수정 권고
- **C급**: 2개 이하, 재작성 필요

## 작업 순서
1. $ARGUMENTS 파일 읽기
2. 각 프롬프트 등급 판정
3. B급은 개선 제안 제시
4. C급은 재작성 초안 제시
5. 찬훈님 승인 후 파일 수정
