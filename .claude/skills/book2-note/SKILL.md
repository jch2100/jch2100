# Book 2 소재 기록 스킬

## 원칙
Book 2 소재는 의도적으로 수집하지 않는다. 프롬프트 라이브러리 작업 중 자연스럽게 발견된 것만 기록한다.

## 작업
1. book2/notes.md를 읽기
2. 오늘 날짜와 $ARGUMENTS 내용을 다음 형식으로 추가:

```
### YYYY-MM-DD
N. **"핵심 인사이트 한 줄"**
   - 맥락: 어떤 작업 중 발견했는지
   - 연결: 관련 연구/경험
```

3. 파일 저장 후 "기록했습니다" 한 줄 확인
