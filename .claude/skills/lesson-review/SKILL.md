# 레슨 적대적 검토 스킬

## 역할

이 스킬은 AI가 만든 레슨을 AI가 공격하는 구조다.
목표는 칭찬이 아니라 결함 발견이다.
"이 정도면 됐지"를 통과시키지 않는 것이 유일한 목적이다.

## 실행 순서

### 1단계: 파일 읽기
$ARGUMENTS 레슨 파일을 읽는다.
HARNESS.md(`math-learning/HARNESS.md`)를 읽는다.

### 2단계: 구조 체크 (7항목)
HARNESS.md의 구조 체크 항목 7개를 하나씩 대조한다.
통과/실패를 명시한다.

### 3단계: 내용 체크 (4항목)
HARNESS.md의 내용 체크 항목 4개를 대조한다.

### 4단계: 사실 공격 (가장 중요)
다음을 하나씩 검토한다.

**인용 공격**
- 인용된 연구자가 실존하는가?
- 연도가 그 연구자의 실제 발표 시점과 맞는가?
- 레슨에 서술된 연구 내용이 실제 연구와 일치하는가?
- AI가 없는 연구를 지어냈을 가능성: 낮음/중간/높음으로 평가

**수식 공격**
- 수식에 계산 오류가 있는가?
- 변수 정의가 명확한가?
- 단위가 맞는가?

**논리 공격**
- 심리학 → 수학 연결에 비약이 있는가?
- 상관관계를 인과관계로 서술한 곳이 있는가?
- "항상", "반드시", "모든" 같은 과잉 일반화가 있는가?

### 5단계: 등급 판정
HARNESS.md 기준으로 A/B/C 등급 판정.
등급과 함께 구체적 수정 항목 목록을 제시한다.

### 6단계: 수정 제안
B급 이하일 경우 수정 초안을 제시한다.
찬훈님 승인 후 파일 수정.

## 출력 형식

```
## 레슨 검토 결과: [파일명]

### 구조 체크
- [통과] 오늘의 질문이 실생활에서 나왔는가
- [실패] ...

### 사실 공격 결과
| 인용 | 실존 여부 | 내용 일치 | 할루시네이션 가능성 |
|------|----------|-----------|-------------------|
| ... | ... | ... | 낮음/중간/높음 |

### 수식 검토
...

### 논리 검토
...

### 최종 등급: A / B / C
수정 필요 항목:
1. ...
2. ...
```

## 주의사항

- 통과 항목도 간략히 명시한다 (칭찬 1줄로 끝낸다)
- 수정 제안은 구체적인 문장으로 한다 ("더 보완 필요" 같은 모호한 표현 금지)
- 인용 검증은 WebSearch를 사용해 실제로 확인한다
