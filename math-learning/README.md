# 시험이 끝나면 수학도 끝난 줄 알았다
**40대가 일상에서 다시 발견한 37가지 수학의 순간**

---

수능이 끝나던 날 수학 책을 덮었다.
그로부터 20년이 넘게 흘렀다.

그런데 세상이 수학으로 돌아가고 있었다.
신호등 타이밍, 음악 BPM, 대출 이자, 투자 손실의 구조.
배운 적 없는데 수학이 작동하고 있었다.

이 책은 공식이 아니라 질문에서 시작한다.

## 이 책의 사용법

공식이 먼저 나오지 않는다. 질문이 먼저다.

각 레슨은 세 가지로 구성된다:
1. **오늘의 질문** — 일상에서 건져 올린 하나의 의문
2. **수학적 깨달음** — 직관 먼저, 공식은 그 다음
3. **직접 해보기** — 계산기 없이 풀 수 있는 연습

순서대로 읽지 않아도 된다.
궁금한 질문이 있는 레슨부터 시작하면 된다.
